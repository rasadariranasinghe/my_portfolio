Youth Workshop Gap Analysis (DA-37) - U+ Education

ExcelData CleaningGap MatrixToronto Open Data
Result: Public speaking stood out as the clearest underserved topic across nine categories, and U+ received a recommendation for three pilot workshops.
Problem

U+ Education needed evidence, not guesswork, on which youth workshop topics Toronto programs already cover well and which ones they leave out.

Data

38,168 recreation program records and 3,306 library program records from Toronto open data.

Method

Standardized both sources into one inventory in Excel, correcting a placeholder maximum age of 120 in 14,220 rows, then built a gap matrix across nine topic categories.

Insight

Most categories were well covered by existing programs; public speaking had the thinnest coverage, making it the strongest opportunity for new U+ workshops.

Volunteer-to-Career Intelligence Platform (DA-42) - U+ Education

Python (Pandas)SQLTableauNOC 2021
Result: A four-page Tableau dashboard the team can explore by NOC category, province, average wage by occupation, and partner prospects.
Problem

U+ needed a reliable way to surface labour-market and occupation trends from a large, messy national job dataset.

Data

147,000+ Canadian Job Bank records.

Method

Clean and validate data with Python/Pandas and SQL, flagging missing values and duplicates, and lead the dashboard and data model development. Applied the NOC 2021 taxonomy to standardize 1,000+ fragmented job titles for consistent reporting.

Insight

With titles standardized and data validated, occupation trends can be compared consistently across provinces and wage levels, instead of being distorted by inconsistent job naming.

AI Concierge Agent (Roomie) - Personal Project

Salesforce AgentforceSalesforce FlowData Modeling
Result: An agent that handles customer onboarding, room booking, and food ordering, and never creates a booking or order for an unvalidated customer.
Problem

Automated bookings and orders are only trustworthy if the customer is verified before anything is created.

Data

Customer records modelled in Salesforce, with onboarding, booking, and ordering data.

Method

Designed and built the agent in Salesforce Agentforce, with Autolaunched Flows that validate each customer before any booking or order is created.

Insight

Putting validation inside the flow, before record creation, prevents bad data at the source instead of cleaning it up afterwards.

Crowdfunding ETL and Database Analysis

PythonPandasPostgreSQLSQLERD
Result: Raw campaign data became four normalized PostgreSQL tables that can be queried consistently with SQL.
Problem

Raw crowdfunding campaign data in a single flat file could not be queried reliably across campaigns, categories, and contacts.

Data

1,000 crowdfunding campaign records and 1,000 contact records from Excel source files, spanning 9 categories and 24 subcategories.

Method

Built an ETL pipeline with Python and Pandas that cleaned the raw data into four normalized tables in a PostgreSQL database designed from an ERD.

Insight

A normalized schema designed up front makes every later SQL query simpler and more consistent.
